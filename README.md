# Ускорь индексацию

Подборка доступных товаров по рекомендациям с учётом исключений и повторений.

Поля «Заполнить» предназначены для ответов по выполненной работе. Достаточно коротких объяснений с опорой на собственный код. Раздел о необязательной части заполняется только при её выполнении.


## Начало работы

[Полное задание](docs/TASK.md). Работа выполняется в собственной копии репозитория.

| Файл | Назначение |
| --- | --- |
| `src/main/kotlin/lab2/Product.kt` | Тип данных |
| `src/main/kotlin/lab2/ProductSelection.kt` | Функция для самостоятельной реализации |
| `src/test/kotlin/lab2/ProductSelectionTest.kt` | Два начальных теста; остальные добавляются самостоятельно |
| `README.md` | Инструкция запуска и ответы по работе |

Запуск всех тестов из корня репозитория:

```bash
./gradlew test
```

Windows PowerShell:

```powershell
.\gradlew.bat test
```

До реализации функции тесты завершаются ошибкой `NotImplementedError` из-за `TODO`. Проверить настройку проекта без выполнения тестов можно командой `./gradlew testClasses` (в Windows — `.\gradlew.bat testClasses`).

В исходном репозитории преподавателя CI проверяет только компиляцию заготовки и тестов. В собственной копии CI выполняет `clean build` с запуском тестов; до реализации он будет красным. При использовании fork может потребоваться включить GitHub Actions во вкладке Actions. Успешная компиляция заготовки не означает выполнения задания.

Перед сдачей выполняется `./gradlew clean build` или `.\gradlew.bat clean build`. Ответы размещаются ниже, ссылка на репозиторий отправляется в Academy.
